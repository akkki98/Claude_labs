# Lab: Data Analysis and Automation with Claude for Excel

## Objective

In this lab, you will use **Claude for Excel** to analyze, clean, transform, summarize, and visualize Excel data using natural language. You will learn how Claude can improve productivity by reducing manual spreadsheet work while maintaining accuracy and consistency.

---

# Learning Outcomes

By the end of this lab, you will be able to:

- Connect Claude for Excel
- Analyze spreadsheet data using natural language
- Clean and transform datasets
- Generate Excel formulas
- Create Pivot Tables and charts
- Perform business analysis
- Summarize large datasets
- Automate repetitive Excel tasks
- Generate insights and recommendations

---

# Prerequisites

- Microsoft Excel (Microsoft 365 recommended)
- Claude for Excel installed and configured
- Sample Excel workbook (Sales_Data.xlsx)
- Internet connection
- Basic Excel knowledge

---

# Lab Dataset

Use a workbook containing multiple worksheets:

- Sales Data
- Customer Data
- Product Master
- Employee Data
- Finance Transactions

Each worksheet should contain approximately 500–1000 records.

# Exercise 1: Explore the Dataset

## Objective

Understand the structure of the workbook.

### Tasks

Ask Claude:

> What columns are available?

# Best Practices

- Use clear and specific prompts.
- Ask one analytical question at a time for better results.
- Verify AI-generated formulas before applying them broadly.
- Review business insights with domain knowledge.
- Keep original data unchanged by working on a copy.
- Use structured tables for more accurate analysis.
- Validate AI recommendations before making business decisions.
